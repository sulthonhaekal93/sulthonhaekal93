# Mahir Membaca

Game latihan membaca untuk anak (seri **Mahir Baca**). Satu file `index.html`, tanpa instalasi — cukup buka di browser atau lewat GitHub Pages: `/mahir-membaca/`.

## 5 Level

| Level | Materi | Mode Belajar | Mode Main (10 soal) |
| --- | --- | --- | --- |
| 1. Kenal Huruf | Huruf vokal & konsonan a–z | Kartu huruf + gambar + bunyi | Dengar lalu pilih huruf, huruf awal gambar, huruf besar → kecil, vokal |
| 2. Suku Kata | Konsonan + vokal: ba bi bu be bo | Pilih konsonan, ketuk suku kata, "Baca semua" | Dengar suku kata, gabung huruf, suku kata awal gambar |
| 3. Kata Mudah | Kata 2–3 suku kata terbuka: bo-la, ba-ju | Kartu kata dieja per suku kata | Pilih nama gambar, susun suku kata, dengar lalu pilih tulisan |
| 4. Kata Seru | Huruf mati, ng, ny, diftong: ku-cing, nya-muk, pu-lau | Kartu kata dieja per suku kata | Susun suku kata, baca kata lalu pilih gambar, lengkapi suku akhir |
| 5. Membaca Kalimat | Kalimat pendek: ini bola adi | Bacaan karaoke kata per kata | Baca kalimat lalu pilih gambar, susun kalimat, kata yang hilang |

## Fitur

- Maskot **Pensi** yang bereaksi (senang, sedih, berbicara).
- Suara bacaan bahasa Indonesia (Text-to-Speech perangkat), efek suara, dan musik latar (bisa dimatikan).
- Bintang 1–3 per level; level berikutnya terbuka setelah level sebelumnya selesai. Kemajuan tersimpan di browser.
- Jawaban salah boleh dicoba lagi; ada tombol "Bantu bacakan" untuk soal membaca.
- Warna dan huruf mengikuti design system **Mahir Learning Series**.
